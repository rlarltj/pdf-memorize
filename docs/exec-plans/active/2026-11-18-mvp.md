# MVP: 추출 → 카드 → 복습 → 동기화 → 배포

- 상태: 진행 중
- 시작: 2026-11-18

## 배경

샘플 PDF(HWP 변환, 배경색 하이라이트)로 추출이 가능함을 확인했다. 실제로 매일 쓸 수 있는 최소 기능을 만들고 공개 URL로 배포한다. 결정이 필요한 항목은 기본값으로 구현하고 아래 "결정 대기"에 모아 한 번에 정한다.

## 목표

- PDF를 올리면 하이라이트로 카드가 만들어지고, 복습 일정에 따라 매일 학습할 수 있다
- 브라우저만으로 동작하고, 로그인하면 기기 간 동기화된다
- Cloudflare Pages로 배포된다

## 비목표

- 스캔본 OCR, LLM 문제 생성, 결제, 모바일 앱

## 데이터·마이그레이션 (7번)

- 로컬(IndexedDB)이 기본 저장소이고 Supabase는 동기화 대상이다. 로그인하지 않아도 모든 기능이 동작한다
- 테이블: `documents`, `cards`, `reviews`. 모두 `user_id` + RLS(`auth.uid() = user_id`)
- 문서·카드는 `updated_at` 기준 last-write-wins. 삭제는 `deleted_at`으로 표시(tombstone)해 다른 기기에도 전파
- 복습 기록은 추가만 하므로 충돌 없음
- 원본 PDF는 올리지 않는다 (ADR 2026-11-18-pdf-client-side-only)

## 테스트

- 동기화 엔진은 원격 API를 인터페이스로 분리하고 메모리 가짜 구현으로 "기기 2대" 시나리오를 검증
- 실제 Supabase 프로젝트 연결 검증은 프로젝트 생성 후 수동

## 롤백

- Supabase 환경 변수를 비우면 로그인 UI가 사라지고 로컬 전용으로 동작한다

## 결정 (2026-11-18)

사용자가 직접 정한 항목은 **굵게**. 나머지는 사용자가 위임해 아래로 정했고, 실제로 써 보고 다시 정한다.

| # | 항목 | 결정 | 위치 |
|---|---|---|---|
| D1 | 회색 음영 | **하이라이트로 인정** (평균 밝기 190~235 회색) | `isHighlightColor` |
| D2 | 노란색 | **두문자 표시이자 하이라이트.** 문구 안 노란 글자는 두문자로 기록, 노란색만 칠한 문구도 하이라이트 | `KEY_LETTER_COLOR` |
| D3 | 두문자 괄호 범위 | 두문자 글자의 절반 이상이 괄호 안에 있는 문구에만 붙임. 없으면 바로 앞 문구 하나 | `findMnemonics` |
| D4 | 카드 유형 | 빈칸 + 두문자(2글자 이상). 괄호 묶음 카드는 만들지 않음 | `cards.ts` |
| D5 | 빈칸 길이 | 글자 수/2, 3~12칸 | `blank()` |

| D8 | 목표 기억률 | **90%** (자기 평가 기반, 자동 채점 없음) | `scheduler.ts` |
| D9 | 세션 안 반복 | 20분 이내 다시 볼 카드 | `LEARN_AHEAD_MS` |
