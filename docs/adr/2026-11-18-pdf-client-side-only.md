# PDF는 브라우저에서만 처리하고 서버에 저장하지 않는다

- 상태: 채택
- 날짜: 2026-11-18

## 배경

서비스 목표 중 하나가 인프라 비용 최소화다. 사용자가 올리는 PDF는 교재·판례 자료 같은 저작물이 많고, 파일 크기도 수 MB 단위다.

## 결정

- PDF 파싱과 하이라이트 추출은 pdf.js로 브라우저에서 한다
- 원본 PDF는 서버로 전송하거나 저장하지 않는다. 서버(DB)에는 추출한 텍스트, 카드, 복습 기록만 저장한다
- PDF 주석이 아닌 글자 배경색(HWP/Word 변환본) 하이라이트를 1차 지원 대상으로 한다. 샘플 PDF가 이 형태였다

## 이유

- 서버 처리·저장 비용이 0이고 트래픽이 늘어도 비용이 늘지 않는다
- 저작물을 서버에 보관하지 않아 저작권·개인정보 부담이 없다
- 텍스트가 살아 있는 PDF는 OCR 없이 색 사각형과 글자 좌표 매칭으로 추출할 수 있다

## 갱신 (2026-11-18, 원문 보기)

- 원문 보기를 위해 원본 PDF를 **사용자 브라우저(IndexedDB)에만** 저장한다. 서버로 보내지 않고 동기화하지도 않는 원칙은 그대로다
- 원문 보기 이전에 추가한 문서는 원본이 없어 같은 PDF를 한 번 다시 올려야 한다 (파일 해시로 같은 파일인지 확인)

## 감수하는 것

- 기기를 바꾸면 원본 PDF는 다시 올려야 한다 (카드와 기록은 동기화됨). 원문 보기도 기기마다 원본이 필요하다
- 스캔본(이미지 PDF)은 브라우저만으로는 품질 있게 처리하기 어려워 지원하지 않는다
